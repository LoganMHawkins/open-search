# Open Search

Native macOS (SwiftUI, macOS 26 Liquid Glass) front end for Context.dev: people, company, brand, web, news, scrape, crawl, map, answers, style guide, file parsing. See `README.md` for the tool list.

## Context.dev conventions

- Env var: `CONTEXT_DEV_API_KEY` (dev fallback only). The app reads the key from the macOS Keychain (`ca.theboldbureau.opensearch`, account `context-dev-api-key`) via `Sources/Core/Keychain.swift`. Never hardcode or commit a key; this repo is public.
- Wrapper module: `Sources/Core/ContextClient.swift` is the only place that talks to `https://api.context.dev/v1`. Add new endpoints as calls from a tool through it.
- Docs: https://docs.context.dev (append `.md` for plain markdown). Source of truth for request/response shapes: https://docs.context.dev/openapi.json
- Endpoints in use and their docs:
  - `POST /web/search` https://docs.context.dev/api-reference/web-scraping/search
  - `POST /web/scrape` https://docs.context.dev/api-reference/web-scraping/scrape
  - `GET /web/urls` https://docs.context.dev/api-reference/web-scraping/map
  - `POST /web/crawl` https://docs.context.dev/api-reference/web-scraping/crawl
  - `POST /web/answers` https://docs.context.dev/api-reference/web-extraction/answers
  - `POST /people/search` https://docs.context.dev/api-reference/people/search
  - `POST /people/enrich` https://docs.context.dev/api-reference/people/enrich
  - `POST /company/search` https://docs.context.dev/api-reference/company/search
  - `POST /news/search` https://docs.context.dev/api-reference/news/search
  - `GET /brand/search`, `POST /brand/retrieve` https://docs.context.dev/api-reference/brand-intelligence/brand
  - `GET /web/styleguide` https://docs.context.dev/api-reference/brand-intelligence/styleguide
  - `POST /parse` https://docs.context.dev/api-reference/utility/parse
  - `GET /org/usage` (credit balance, 0 credits)
- Not built: batches, monitors, webhooks, `/web/extract`, `/web/fonts`, `/web/naics`, `/web/sic`, logs, feedback.
- Every real call costs credits. Do not loop live calls. Use the debug demo mode (below) for UI work.
- `news/search` `filterBy` accepts only one of sourceDomain / sourceCountry / articleLanguage / articleType at a time (date range can combine). Natural-language news queries need 2+ characters.
- The REST brand profile (`logos[]`, `links{}`) is richer than the MCP card (`logo`, `links[]`); `BrandProfileView` accepts both.

## Working on it

- Build + install: `./build.sh` (XcodeGen, signs with Apple Development identity if present, installs to `~/Applications/Open Search.app`). The `.xcodeproj` is generated and git-ignored.
- Debug screenshots without credits: launch the Debug build with `--tool <rawValue> --demo` (order matters: `--tool` first), plus `--empty` for the idle state, `--light` for light mode. Fixtures live in `Sources/Core/DemoData.swift` (synthetic data only).
- Country / language pickers come from `Sources/Core/Options.swift`, generated by `Tools/gen-options.py`. Do not edit by hand.
- Icon + logo come from `LogoMark` in `Sources/Core/Theme.swift`. After changing it run `Tools/make-icon.sh`.
- Design: Liquid Glass surfaces (`GlassCard`, `.glassEffect`), orange accent `Brand.orange`, Instrument Serif for display (`Brand.display`). Use `.buttonStyle(.softGlass)` for secondary buttons (the system `.glass` style inherits the orange tint and fills solid) and `.glassProminent` + orange tint for the one primary action.
- `AsyncImage` cannot draw SVG (many brand logos are SVG): use `RemoteImage`.
- JSON accessors: `JSON` has real members `str`, `nonEmpty`, `display`, `num`, `int`, `flag`, `list`, `dict`, `strings`, `isNull`, `isBlank`, `isScalar`, `any`, `pretty`. API fields that collide (e.g. `location.display`) must be read with subscripts: `json["display"]`.
